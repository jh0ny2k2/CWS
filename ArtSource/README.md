# Fuentes de arte (ArtSource)

Aquí van los archivos editables de los assets: `.blend`, `.psd`, `.sbsar`, etc.

- Los binarios se guardan con Git LFS (`.blend`, `.psd` ya están configurados).
- Cada fuente debe corresponder a una entrada de `docs/assets_manifest.json`.
- Los assets exportados van a `Content/ConstructionWorld/`.
- Convención de exportación: X delante, Z arriba, escala 1 unidad = 1 cm.
